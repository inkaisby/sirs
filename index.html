Cara Aktifkan Google di Supabase Dashboard:
  1. Buka Supabase Dashboard proyek (whbinarvynbyemvqbfjg).
  2. Masuk ke menu Authentication > Providers > pilih Google.
  3. Nyalakan toggle Enable Google provider.
  4. Masukkan Client ID & Client Secret dari Google Cloud Console.
  5. Daftarkan Authorized Redirect URI:
    https://whbinarvynbyemvqbfjg.supabase.co/auth/v1/callback
